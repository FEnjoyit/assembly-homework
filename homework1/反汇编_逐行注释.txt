传统方式一：LEA
0E00:0000 B8010E            MOV     AX,0E01  ; 取已重定位的数据组段地址（本次为 0E01H）
0E00:0003 8ED8              MOV     DS,AX  ; 初始化 DS，使 DS 指向数据组
0E00:0005 8D160200          LEA     DX,[0002]  ; 把 Hello 的有效偏移地址 0002H 放入 DX，不读取字符串内容
0E00:0009 B409              MOV     AH,09  ; 选择 DOS 09H 号显示字符串服务
0E00:000B CD21              INT     21  ; 从 DS:DX 输出字符，遇到 24H（$）结束
0E00:000D B8004C            MOV     AX,4C00  ; AH=4CH 选择退出服务；AL=00H 表示返回码为 0
0E00:0010 CD21              INT     21  ; 结束程序并返回 DOS

传统方式二：MOV OFFSET
0E00:0000 B8010E            MOV     AX,0E01  ; 取已重定位的数据组段地址（本次为 0E01H）
0E00:0003 8ED8              MOV     DS,AX  ; 初始化 DS，使 DS 指向数据组
0E00:0005 BA0200            MOV     DX,0002  ; 把链接后的偏移立即数 0002H 放入 DX
0E00:0008 B409              MOV     AH,09  ; 选择 DOS 09H 号显示字符串服务
0E00:000A CD21              INT     21  ; 从 DS:DX 输出字符，遇到 24H（$）结束
0E00:000C B8004C            MOV     AX,4C00  ; AH=4CH 选择退出服务；AL=00H 表示返回码为 0
0E00:000F CD21              INT     21  ; 结束程序并返回 DOS

直接写内存方式
0DA6:0100 8CC8              MOV     AX,CS  ; 复制当前代码段到 AX，避免硬编码运行时段地址
0DA6:0102 8ED8              MOV     DS,AX  ; DS=CS，让字符串与代码使用同一个段
0DA6:0104 BA0002            MOV     DX,0200  ; DX=0200H，必须与字符串写入偏移 0200H 一致
0DA6:0107 B409              MOV     AH,09  ; AH=09H，选择显示字符串服务
0DA6:0109 CD21              INT     21  ; 输出 DS:0200H 处以 $ 结束的字符串
0DA6:010B B8004C            MOV     AX,4C00  ; AX=4C00H，正常退出并返回 0
0DA6:010E CD21              INT     21  ; 结束程序并返回 DOS

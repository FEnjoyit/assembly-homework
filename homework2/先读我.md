# 文件入口

- `作业2_报告.md`：完整作业报告，包含三份源码、算法解释、真实 C 反汇编及中文注释。
- `src`：两份 MASM 汇编程序、一份标准 C 程序和两份 DOS 批处理文件。
- `bin`：三份已验证的 16 位 DOS EXE，在 DOSBox 中运行。
- `C反汇编_逐行注释.txt`：真实可执行文件 main 函数的逐条中文注释。
- `output`：三份程序实际输出。
- `logs`：实际编译日志、DEBUG 原始记录、MASM 列表、C 映射及目标文件反汇编。
- `验证结果.json`：30 项检查结果及可执行文件校验值。

在本机课程根目录双击 `运行作业2.cmd`，可演示三个已完成程序。所有文件均位于当前课程文件夹下。

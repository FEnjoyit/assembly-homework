# 作业题目 2：按要求打印 ASCII 表

完成日期：2026-10-09。

## 一、题目要求与输出格式

输出 ASCII 表中的小写字母部分，每行 13 个小写字母，并分别完成：

1. 用 `LOOP` 指令实现，注意双重循环中 `CX` 值的保存和恢复。
2. 用条件跳转指令实现。
3. 用 C 语言实现，查看真实反汇编代码并加注释。

按照题目图片中示例的排版，在相邻字母之间添加一个空格。每行有 13 个字母和 12 个分隔空格；行首、行尾均无多余空格。预期输出为：

```text
a b c d e f g h i j k l m
n o p q r s t u v w x y z
```

小写字母的 ASCII 编码范围是 `61H` 至 `7AH`，对应十进制 97 至 122，共 26 个字母；因此使用 2 行、每行 13 个字母的两层循环。

## 三、LOOP 指令实现

源文件：[A2LOOP.ASM](src/A2LOOP.ASM)。

```asm
; Assignment 2, part 1: lowercase ASCII, 13 letters per line.
; MASM 5.0, 8086, 16-bit DOS. Save as ASCII or GBK without BOM.
; Both row and column loops use LOOP. PUSH/POP preserve outer CX.

STACKSEG SEGMENT STACK
    DW 128 DUP (?)
STACKSEG ENDS

CODESEG SEGMENT
    ASSUME CS:CODESEG, SS:STACKSEG
START:
    MOV BL, 'a'             ; BL = next lowercase ASCII character.
    MOV CX, 2               ; Outer loop: two rows.
ROW_LOOP:
    PUSH CX                 ; Save the outer counter before reusing CX.
    MOV CX, 13              ; Inner loop: thirteen letters in this row.
COL_LOOP:
    MOV DL, BL
    MOV AH, 02H             ; DOS function 02H: print character in DL.
    INT 21H
    INC BL                  ; Next ASCII letter, a through z.
    CMP CX, 1               ; The last letter needs no following space.
    JE ROW_END              ; Formatting only; not a loop-control jump.
    MOV DL, ' '
    MOV AH, 02H
    INT 21H
ROW_END:
    LOOP COL_LOOP           ; CX = CX - 1; repeat while CX is nonzero.
    MOV DL, 0DH             ; DOS line ending: CR followed by LF.
    MOV AH, 02H
    INT 21H
    MOV DL, 0AH
    MOV AH, 02H
    INT 21H
    POP CX                  ; Restore the outer counter (2, then 1).
    LOOP ROW_LOOP           ; Next row; stops after exactly two rows.
    MOV AX, 4C00H           ; Return to DOS with exit code zero.
    INT 21H
CODESEG ENDS
END START
```

### 关键说明

- `BL` 保存当前字母编码，初值为 `'a'`；每输出一个字母后执行 `INC BL`。
- 外层循环的 `CX` 初值为 2，控制两行输出；内层循环的 `CX` 初值为 13，控制每行字母数量。
- 内层开始前先执行 `PUSH CX`，然后把 `CX` 改为 13。内层结束、换行之后执行 `POP CX`，外层 `LOOP` 才能使用正确的行计数。
- `LOOP COL_LOOP` 和 `LOOP ROW_LOOP` 分别控制内外层循环。`JE ROW_END` 仅用于跳过行尾空格，不承担循环计数工作。
- `INT 21H` 的 `AH=02H` 功能输出 `DL` 中的字符。每行结束依次输出 `0DH` 和 `0AH`，即 DOS 的回车、换行。
- 显式栈段提供 `PUSH/POP` 所需的栈空间；程序通过 `INT 21H / AH=4CH` 正常返回 DOS。

### CX 保存和恢复的实际检查

使用 `debug a2loop.exe`，先执行 `g=0 2b`，在第一行结束、执行完 `POP CX` 后停止，再连续单步观察：

| 停止位置 | CX | SP | 说明 |
| --- | --- | --- | --- |
| `IP=002B`，即外层 `LOOP` 之前 | `0002` | `0100` | 外层行计数已从栈恢复 |
| 执行外层 `LOOP` 后，`IP=0005` | `0001` | `0100` | 外层计数减 1，进入第二行 |
| 执行 `PUSH CX` 后，`IP=0006` | `0001` | `00FE` | 将第二行的外层计数压栈保存 |
| 执行 `MOV CX,13` 后，`IP=0009` | `000D` | `00FE` | 内层循环初始化为十进制 13 |

随后执行 `g`，正确输出第二行，并显示 `Program terminated normally (0000)`。完整原始记录见 [A2CX.OUT](logs/A2CX.OUT)。当前 DEBUG 将 16 位 `LOOP` 显示为 `LOOPW`；这是同一条指令的显示形式。

## 四、条件跳转指令实现

源文件：[A2JUMP.ASM](src/A2JUMP.ASM)。

```asm
; Assignment 2, part 2: the same output using conditional jumps.
; MASM 5.0, 8086, 16-bit DOS. No LOOP instruction is used.

STACKSEG SEGMENT STACK
    DW 128 DUP (?)
STACKSEG ENDS

CODESEG SEGMENT
    ASSUME CS:CODESEG, SS:STACKSEG
START:
    MOV BL, 'a'             ; ASCII 61H, the first lowercase letter.
    MOV SI, 2               ; SI counts the two rows.
ROW_LOOP:
    MOV DI, 13              ; DI counts thirteen letters in each row.
COL_LOOP:
    MOV DL, BL
    MOV AH, 02H
    INT 21H                 ; Print the current letter.
    INC BL
    CMP DI, 1
    JE ROW_END              ; Skip the space after the last letter.
    MOV DL, ' '
    MOV AH, 02H
    INT 21H
ROW_END:
    DEC DI                  ; DEC sets ZF according to the new count.
    JNZ COL_LOOP            ; ZF = 0 means more columns remain.
    MOV DL, 0DH
    MOV AH, 02H
    INT 21H
    MOV DL, 0AH
    MOV AH, 02H
    INT 21H
    DEC SI
    JNZ ROW_LOOP            ; Repeat while more rows remain.
    MOV AX, 4C00H
    INT 21H
CODESEG ENDS
END START
```

`SI` 保存剩余行数，`DI` 保存本行剩余字母数。每次循环分别通过 `DEC DI / JNZ COL_LOOP` 和 `DEC SI / JNZ ROW_LOOP` 完成减计数与条件跳转。

`DEC` 会根据结果设置零标志 `ZF`：计数还未减到 0 时 `ZF=0`，`JNZ` 跳回继续输出；减到 0 时 `ZF=1`，停止对应循环。本版本未使用 `LOOP` 指令。

两个版本均可输出 26 个字母。LOOP 版本必须处理嵌套循环共用 `CX` 的问题；条件跳转版本通过两个不同寄存器分别保存计数。

## 五、C 语言实现及反汇编注释

源文件：[A2C.C](src/A2C.C)。

```c
/* Assignment 2, part 3: compile for 8086, 16-bit DOS. */
#include <stdio.h>
/* Keep putchar as a function call for readable disassembly. */
#undef putchar

int main(void)
{
    int row;
    int col;
    int ch = 'a';

    for (row = 0; row < 2; ++row) {
        for (col = 0; col < 13; ++col) {
            putchar(ch);
            ++ch;
            if (col < 12) {
                putchar(' ');
            }
        }
        putchar('\n');
    }
    return 0;
}
```

`row` 从 0 至 1，控制两行；`col` 从 0 至 12，控制每行 13 个字母；`ch` 从 `'a'` 逐次递增。`col < 12` 时输出分隔空格，每行最后输出换行。

这里用 `#undef putchar` 取消头文件中该名字的宏展开，让反汇编中的每次字符输出都对应明确的 `CALL putchar_`，便于逐行解释。

### 编译、反汇编来源

在 Windows 中为工具设置本课程的 `WATCOM`、`INCLUDE` 和工具搜索路径后，实际执行：

```text
wcl -0 -ms -bt=dos -l=dos -od -d2 -s -w=4 -we -fe=A2C.EXE -fo=A2C.OBJ -fm=A2C.MAP A2C.C
wdis -s=A2C.C -l=A2C_DIS.TXT A2C.OBJ
```

编译记录显示 `0 warnings, 0 errors`。WDIS 得到的原始目标文件反汇编见 [A2C_DIS.TXT](logs/A2C_DIS.TXT)。

另外在 DOSBox 的 DEBUG 中直接查看链接后的可执行文件：

```text

u cs:10 l5d
g 10
r
g
q
```

链接映射文件确认 `main_` 位于 `0000:0010`，`putchar_` 位于 `0000:006D`。程序入口先执行 C 运行库启动代码；`g 10` 可以在进入 `main` 时暂停，而后执行 `g` 正常运行完成。

下面是 **真实 A2C.EXE 的 main 函数反汇编**，保留偏移地址和实际机器码，再逐条添加中文注释。原始记录见 [A2CDIS.OUT](logs/A2CDIS.OUT)，独立注释文件见 [C反汇编_逐行注释.txt](C反汇编_逐行注释.txt)。

```text
0011  51           PUSH    CX                           ; 保存 CX 寄存器。
0012  52           PUSH    DX                           ; 保存 DX 寄存器。
0013  56           PUSH    SI                           ; 保存 SI 寄存器。
0014  57           PUSH    DI                           ; 保存 DI 寄存器。
0015  55           PUSH    BP                           ; 保存原 BP，以便建立并最终恢复栈帧。
0016  89E5         MOV     BP,SP                        ; 以 BP 定位栈帧中的局部变量。
0018  81EC0800     SUB     SP,0008                      ; 在栈上分配 8 字节，存放三个 int 变量及返回值临时槽。
001C  C746FE6100   MOV     WORD PTR [BP-02],0061        ; ch = 0061H，即十进制 97，对应小写字母 'a'。
0021  C746FA0000   MOV     WORD PTR [BP-06],0000        ; row = 0，初始化外层 for 的行计数。
0026  837EFA02     CMP     WORD PTR [BP-06],+02         ; 比较 row 与 2；row 在 [BP-06] 中。
002A  7D30         JGE     005C                         ; row >= 2 时跳到 005C，结束外层循环并准备返回。
002C  C746FC0000   MOV     WORD PTR [BP-04],0000        ; col = 0，每进入新一行都重新初始化列计数。
0031  837EFC0D     CMP     WORD PTR [BP-04],+0D         ; 比较 col 与 000DH，即十进制 13。
0035  7D1A         JGE     0051                         ; col >= 13 时跳到 0051，结束本行并输出换行。
0037  8B46FE       MOV     AX,[BP-02]                   ; 把 ch 装入 AX，作为本工具链 putchar 的参数。
003A  E83000       CALL    006D                         ; 调用 006D 处的 putchar_，输出当前小写字母。
003D  FF46FE       INC     WORD PTR [BP-02]             ; ++ch，将字符编码递增 1。
0040  837EFC0C     CMP     WORD PTR [BP-04],+0C         ; 比较 col 与 000CH，即十进制 12。
0044  7D06         JGE     004C                         ; col >= 12 时跳过空格，避免在每行最后一个字母后多输出空格。
0046  B82000       MOV     AX,0020                      ; AX = 0020H，即空格的 ASCII 编码。
0049  E82100       CALL    006D                         ; 调用 putchar_，输出字母之间的分隔空格。
004C  FF46FC       INC     WORD PTR [BP-04]             ; ++col，将本行列计数递增 1。
004F  EBE0         JMP     0031                         ; 跳回 0031，继续检查内层 for 的循环条件。
0051  B80A00       MOV     AX,000A                      ; AX = 000AH，即 C 源码中的换行符。
0054  E81600       CALL    006D                         ; 调用 putchar_ 输出换行；DOS 文本运行库产生 CR/LF 行结束。
0057  FF46FA       INC     WORD PTR [BP-06]             ; ++row，将行计数递增 1。
005A  EBCA         JMP     0026                         ; 跳回 0026，继续检查外层 for 的循环条件。
005C  C746F80000   MOV     WORD PTR [BP-08],0000        ; 把返回值临时槽 [BP-08] 置为 0，对应 return 0。
0061  8B46F8       MOV     AX,[BP-08]                   ; 把返回值装入 AX；16 位 int 返回值放在 AX 中。
0064  89EC         MOV     SP,BP                        ; 恢复 SP，释放 main 在栈上分配的局部变量空间。
0066  5D           POP     BP                           ; 恢复原 BP。
0067  5F           POP     DI                           ; 恢复 DI。
0068  5E           POP     SI                           ; 恢复 SI。
0069  5A           POP     DX                           ; 恢复 DX。
006A  59           POP     CX                           ; 恢复 CX。
006B  5B           POP     BX                           ; 恢复 BX。
006C  C3           RET                                  ; 返回 C 运行库的调用者，由运行库完成程序退出。
```

### 反汇编解读

| 栈位置 | 对应 C 变量 |
| --- | --- |
| `[BP-02]` | `ch` |
| `[BP-04]` | `col` |
| `[BP-06]` | `row` |
| `[BP-08]` | 返回值临时槽 |

两个 `for` 循环对应比较指令、条件跳转、计数递增和向前面的条件判断位置跳转。本工具链对 `putchar` 使用寄存器传参，在实际指令中可见字符参数放入 `AX` 后调用 `006D`。解释调用约定时应以当前编译器和实际代码为准。

`main` 的代码长度是 `005DH`，即 93 字节。WDIS 的目标文件记录中 `CALL` 的位移可能为 `0000`，其符号引用需要由链接器重定位；上面使用链接后的 EXE 记录，因此三个调用的实际目标都已确定为 `006D`。

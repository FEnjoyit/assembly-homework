# 课堂练习1：进制转换

## 一、实验目的

1. 输入1至2位十六进制数，输出对应的十进制数。
2. 实现追加部分：输入十进制数，输出对应的十六进制数。
3. 通过数位累加、除法取余和栈操作，理解 ASCII 字符与二进制数值之间的转换。

程序采用 MASM 5.00 和 LINK 3.60 编译链接，在 DOSBox-X 2026.10.01 中运行，指令适用于8086。

## 二、输入输出约定

| 程序 | 输入 | 输出 |
| --- | --- | --- |
| `C1H2D.EXE` | 1至2位十六进制数，范围为 `0～FF`，支持 `A～F`、`a～f` | 对应十进制数，范围为 `0～255` |
| `C1D2H.EXE` | 1至5位十进制数，数值范围为 `0～65535` | 大写十六进制数，范围为 `0～FFFF` |

输入以回车结束，直接填写数字，不带 `0x`、正负号或空格。允许长度范围内的前导零，例如 `0f`、`00255`。输出省略前导零，数值为零时输出 `0`。空输入、非法字符、超长输入和十进制越界输入均显示错误提示并重新输入。

## 三、十六进制转十进制

源文件：[C1H2D.ASM](src/C1H2D.ASM)，可执行文件：[C1H2D.EXE](bin/C1H2D.EXE)。

### 1. 读取并检查输入

使用 DOS `INT 21H` 的 `AH=0AH` 功能读取整行。输入缓冲区定义为：

```asm
INPUT DB 80,0,80 DUP (0)
```

第一个字节表示缓冲区容量，第二个字节由 DOS 填写实际输入长度，字符从第三个字节开始。读取后检查长度是否为1或2，再逐个检查字符。较大的读取缓冲区使程序能够检查超出题目长度的输入。

### 2. 将字符转换为数位

| ASCII 字符范围 | 数位值 |
| --- | --- |
| `'0'～'9'` | 字符减去 `'0'`，得到 `0～9` |
| `'A'～'F'` | 字符减去 `'A'` 再加10，得到 `10～15` |
| `'a'～'f'` | 字符减去 `'a'` 再加10，得到 `10～15` |

子程序 `HEX_DIGIT` 通过 AL 返回数位值，通过进位标志 CF 返回检查结果：合法时 `CF=0`，非法时 `CF=1`。主程序用 `JC INVALID` 转入错误处理。

### 3. 按位累加

设当前数值为 `V`，新读入数位为 `d`，则：

```text
V = V × 16 + d
```

用 BX 保存累计值，每读入一位，先左移4位，再加上新数位：

```asm
MOV AL,[SI]
CALL HEX_DIGIT
JC INVALID
SHL BX,1
SHL BX,1
SHL BX,1
SHL BX,1
XOR AH,AH
ADD BX,AX
INC SI
LOOP HEX_NEXT
```

8086 的移位次数可用常数1或 CL。本程序连续执行四条 `SHL BX,1`，既完成乘16，也保留 CX 的循环计数。

以输入 `ff` 为例，第一位得到 `0×16+15=15`，第二位得到 `15×16+15=255`。

### 4. 输出十进制字符

数值255在寄存器中的二进制表示与字符 `'2'`、`'5'`、`'5'` 不同，输出前需要拆分十进制数位。将数值反复除以10：

| 被除数 | 商 | 余数 |
| --- | --- | --- |
| 255 | 25 | 5 |
| 25 | 2 | 5 |
| 2 | 0 | 2 |

余数按低位到高位产生，因此每次将余数压栈，最后依次弹出，得到 `2、5、5`。数位加上 `'0'` 后，通过 `AH=02H`、`DL=字符` 调用 `INT 21H` 输出。

```asm
MOV BX,10
XOR CX,CX
DEC_DIVIDE:
    XOR DX,DX
    DIV BX
    PUSH DX
    INC CX
    OR AX,AX
    JNZ DEC_DIVIDE
DEC_OUTPUT:
    POP DX
    ADD DL,'0'
    MOV AH,02H
    INT 21H
    LOOP DEC_OUTPUT
```

`DIV BX` 将 `DX:AX` 组成的32位无符号被除数除以 BX，商在 AX，余数在 DX。每次先将 DX 清零，使本次被除数等于 AX 中的16位数值。循环至少执行一次，所以输入零也会压入并输出一位 `0`。

## 四、十进制转十六进制

源文件：[C1D2H.ASM](src/C1D2H.ASM)，可执行文件：[C1D2H.EXE](bin/C1D2H.EXE)。

### 1. 解析十进制数

只接收 `'0'～'9'`，每读入一位执行：

```text
V = V × 10 + d
```

AX 保存累计值，BX 保存乘数10，DI 暂存新数位。16位无符号数的最大值为65535。乘法和加法都要检查越界：

```asm
MOV DI,DX
MUL BX
OR DX,DX
JNZ INVALID
ADD AX,DI
JC INVALID
```

`MUL BX` 的完整结果位于 `DX:AX`。若 DX 非零，说明乘积已超出16位范围；加上新数位后，若 CF 为1，则加法产生进位，同样判为越界。

输入 `65536` 时，前四位形成6553，乘10得到65530，再加6产生进位，因此拒绝该输入并重新提示。输入 `70000` 时，最后一次乘法得到70000，DX 非零，也会被拒绝。

### 2. 按16取余输出

反复除以16，将余数压栈。余数 `0～9` 转成 `'0'～'9'`，余数 `10～15` 转成 `'A'～'F'`。按栈的后进先出顺序输出，得到高位在前的十六进制字符串。

```asm
POP DX
CMP DL,9
JBE HEX_NUMBER
ADD DL,'A'-10
JMP HEX_WRITE
HEX_NUMBER:
    ADD DL,'0'
HEX_WRITE:
    MOV AH,02H
    INT 21H
    LOOP HEX_OUTPUT
```

例如 `255÷16=15` 余15，`15÷16=0` 余15，最终输出 `FF`；65535对应 `FFFF`。

## 五、主要寄存器与栈

| 寄存器 | 作用 |
| --- | --- |
| AX | 十进制解析的累计值、乘除法的操作数；AH 同时用于指定 DOS 服务 |
| BX | 十六进制解析的累计值，或乘除法中的基数10、16 |
| CX | 输入字符数量、循环计数、待输出数位数量 |
| DX | DOS 字符串偏移、乘法结果高16位、除法余数；DL 用于输出单个字符 |
| SI | 指向当前输入字符，处理一位后加1 |
| DI | 在十进制解析时暂存新数位，避免 MUL 改写 DX 后丢失该数位 |
| DS | 程序数据段，由 `MOV AX,@DATA`、`MOV DS,AX` 初始化 |
| SS:SP | 管理返回地址、寄存器保存和余数栈 |

输出子程序先保存 AX、BX、CX、DX，再用栈倒置余数，所有余数弹出后恢复寄存器。输入解析和输出使用不同阶段的 CX，输出子程序中的 PUSH/POP 保留调用前的计数。

## 六、编译与运行

在 DOSBox 中挂载本练习目录，并将课程 MASM、LINK 所在目录加入 DOS PATH。进入源码目录后执行：

```text
cd \src
masm C1H2D.ASM,C1H2D.OBJ,C1H2D.LST;
link C1H2D.OBJ,C1H2D.EXE,C1H2D.MAP;
masm C1D2H.ASM,C1D2H.OBJ,C1D2H.LST;
link C1D2H.OBJ,C1D2H.EXE,C1D2H.MAP;
C1H2D
C1D2H
```

也可以运行 `C1BUILD` 完成两份程序的汇编链接。目录 `bin` 中提供已编译版本，挂载本目录后可直接运行 `bin\c1h2d` 和 `bin\c1d2h`。

课程环境中，源码和 EXE 同时位于 `D:\WORK`，可直接输入 `c1h2d` 或 `c1d2h`。

## 八、实验结论

输入字符先依据 ASCII 编码转换为数位，再按“累计值乘基数加新数位”构成二进制数值；输出时按目标基数反复除法取余，用栈调整数位顺序，最后转换为 ASCII 字符显示。两种转换共享这一过程，差别在于输入和输出所使用的基数。
